# パケットの大冒険

ブラウザに URL を入力してからログインするまでに、ネットワークで何が起きているかを **1 ステップずつ操作して学べる** シミュレーターです。

**公開 URL：https://cuuuutux.github.io/packet-adventure/**

## 何がわかるか

| ステージ | 内容 |
|---|---|
| ① DNS 名前解決 | ドメイン名から IP アドレスを調べる（UDP/53） |
| ② TCP 接続 | 3 ウェイハンドシェイク（SYN → SYN+ACK → ACK）とシーケンス番号 |
| ③ TLS 暗号化の準備 | TLS 1.3 の ClientHello / ServerHello、証明書、鍵交換（HTTPS のみ） |
| ④ HTTP | ページの取得（GET）、ログイン（POST）、リダイレクト、Cookie |
| ⑤ 切断 | FIN / ACK による接続の終了 |

## 主な機能

- **再生／一時停止／前後移動／スライダー／速度切替**（キーボード：← → で前後、Space で再生・停止）
- **🔒 HTTPS ⇄ 🔓 HTTP 切替**：同じ通信を暗号化あり・なしで比べられる
- **👀 盗聴者モード**：同じ Wi-Fi にいる盗聴者に何が見えるかを表示。HTTP ではパスワードが丸見えになり、HTTPS でも DNS・SNI・IP アドレス・通信量は見えることがわかる
- **💥 パケットロス**：SYN が途中で消え、TCP が再送する様子を見られる
- **パケットの中身**：IP → TCP/UDP → TLS → HTTP のヘッダを層ごとに表示
- **好きな URL を入力**：アドレスバーに入力した URL で全ステップを表示（本物のサーバーには接続しない）
- **用語集**（意味・由来・覚え方）と **よくある質問**
- ライト／ダーク切替、スマートフォン表示に対応

## 技術構成

- HTML / CSS / JavaScript のみ（ライブラリ・ビルド不要）
- ネットワーク図とアニメーションはインライン SVG ＋ `requestAnimationFrame`
- GitHub Pages で公開

```
index.html        画面の骨組み
css/style.css     デザイン（ライト / ダーク）
js/steps.js       各ステップの教材データ（解説・ヘッダ・盗聴者の見え方）
js/glossary.js    用語集
js/faq.js         よくある質問
js/app.js         画面の描画・アニメーション・操作
```

## 工夫した点

- **技術的な正確さ**：TCP の番号、TLS 1.3 の流れ、HTTP の動きを RFC（1035 / 9293 / 6298 / 8446 / 9110 / 6265）と照らし合わせて確認した
- **セキュリティ**：入力された URL は画面の HTML に埋め込まれるため、使える文字を厳しく制限して XSS（スクリプトの埋め込み攻撃）を防いでいる
- **安全な例示**：IP アドレスは文書用の予約アドレス（RFC 5737）、ドメインは `example.com`（RFC 2606）を使っている

## 注意

学習用のシミュレーションです。実際の通信は行いません。入力した URL の場合、IP アドレス・バイト数・番号は学習用の値です。

## 実行方法

`index.html` をブラウザ（Edge / Chrome）で開くだけで動きます。
